Metodología

Cómo se construye la relación entre producto, fracción y empresa

El dashboard no confirma operaciones exactas por empresa. Organiza datos públicos para crear una aproximación útil para exploración comercial.

El usuario parte de una búsqueda sencilla de producto. Esa búsqueda filtra el universo de fracciones arancelarias relacionadas.

Las fracciones se comparan usando indicadores como valor comercial, volumen o relevancia dentro de la búsqueda.

La relación empresa-fracción se aproxima mediante ramas económicas o sectores relacionados. Esta unión sirve para exploración, no para validación definitiva.

Power BI integra buscadores, ranking, tarjeta de empresa destacada y mapa para convertir la información en una herramienta navegable.

Limitaciones

El dashboard orienta la investigación, no sustituye validación comercial

La relación entre fracción arancelaria y empresa se construye mediante una aproximación por rama o sector económico. Por eso, el reporte no debe interpretarse como prueba de que una empresa importe, exporte o venda exactamente una fracción específica.

Su uso más adecuado es como filtro inicial para reducir el universo de búsqueda y priorizar empresas o sectores que después deben validarse con investigación comercial directa.

Configuración rápida

Dónde pegar tu iframe de Power BI

En script.js, reemplaza el valor vacío de POWER_BI_EMBED_URL con el enlace que aparece dentro de src="..." en el iframe de Power BI. 

const POWER_BI_EMBED_URL = "https://app.powerbi.com/view?r=TU_CODIGO";
